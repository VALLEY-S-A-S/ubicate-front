# Frontend — Autenticación, activación e importación de usuarios

Rama: `feature/auth-roles-importacion-front`, desde `dev`. Backend requerido: B1–B6 de `feature/auth-roles-importacion-back`. Móvil se implementará después en `feature/auth-roles-importacion-movil`.

1. Configuración inicial: consultar bootstrap-status, mostrar registro solo si requiresSetup=true; manejar carga, error recuperable y cierre concurrente. Pedir X-Bootstrap-Key en campo de contraseña, solo en memoria. Creación de ADMIN verificado conduce a login, sin correo pendiente. Nunca incluir la clave en VITE_*, almacenamiento ni URL.
2. Sesión administrativa: restaurar token con GET /api/auth/me antes de mostrar panel, obtener rol desde servidor y conservar acceso web solo ADMIN/ADMINISTRADOR. Manejar expiración/401 y logout remoto. Mantener rutas públicas de activación y reenvío accesibles aunque haya una sesión administrativa.
3. Activación: ruta /#/activar-cuenta?token=... para todos los roles, nueva contraseña y confirmación, política del backend, estados de enlace inválido/vencido/usado, éxito sin auto-login y orientación web/móvil. Token solo en memoria/fragmento durante el formulario; limpiar fragmento al terminar. Reenvío público con correo institucional y espera de 30 segundos, sin prometer entrega.
4. Usuarios: módulo administrativo /#/dashboard/usuarios con descarga de plantilla, archivo .xlsx hasta 5 MiB, carga multipart, errores 422 por fila, conflictos 409 sin reintento automático, resumen por fila/estado y consulta de lote por id. Polling mientras haya PENDIENTE/ENVIANDO, cancelado al navegar. Reintentar correos fallidos sin duplicar importación. Limitar acciones simultáneas y conservar feedback de resultado.
5. Verificación: tests del cliente HTTP (JSON/multipart/blob/errores), rutas con parámetros, política de contraseñas, persistencia de sesión y validación de archivo; pruebas de interfaz cuando las herramientas disponibles lo permitan. Ejecutar npm test, npm run lint y npm run build. Documentar comprobación integrada con backend y SMTP sandbox. No modificar prototipos HTML locales ni otras ramas/repos.
